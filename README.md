# Grafici R134a - Fisica Tecnica

Repository contenente il codice Python utilizzato per rappresentare i diagrammi termodinamici del refrigerante R134a.

## Contenuto

- Diagramma T-s del R134a
- Diagramma p-v del R134a
- Campana di saturazione
- Curve a titolo costante
- Isobare, isoterme e isoentalpiche
- Punti del ciclo della pompa di calore
